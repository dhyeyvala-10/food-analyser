# Food Analyser 🍎

A professional, interactive web application that analyzes food product ingredients and provides detailed health information with pros, cons, and safety ratings in a hierarchical format.

## 🌟 Features

### Core Functionality
- **Smart Ingredient Analysis**: Paste or type food product ingredients and get instant, comprehensive analysis
- **Extensive Database**: Includes 50+ common food ingredients across multiple categories
- **Detailed Breakdown**: Each ingredient shows:
  - Clear description of what it is
  - Its purpose in the product
  - Health benefits (Pros)
  - Potential concerns (Cons)
  - Safety rating (1-10 scale)

### Hierarchical Display
Professional tree-like structure organizing ingredients by category:
- 🥗 Natural Ingredients
- 💊 Vitamins & Minerals
- 🍬 Sweeteners
- 🧪 Additives & Preservatives
- 🎨 Artificial Colors & Flavors
- 🔬 Emulsifiers
- ✨ Flavor Enhancers

### User Interface
- **Modern, Clean Design**: Professional appearance with smooth animations
- **Fully Responsive**: Works seamlessly on desktop, tablet, and mobile devices
- **Color-Coded Indicators**:
  - 🟢 Green: Excellent/Safe (8-10/10)
  - 🟡 Yellow/Lime: Good/Moderate (6-7.9/10)
  - 🟠 Orange: Moderate Concern (4-5.9/10)
  - 🔴 Red: Significant Concerns (1-3.9/10)
- **Collapsible Sections**: Easy navigation with expandable/collapsible categories
- **Overall Health Score**: Visual circular progress indicator showing product's overall rating
- **Search/Filter**: Real-time ingredient filtering
- **Loading States**: Smooth loading animation during analysis
- **Accessibility**: ARIA labels, keyboard navigation, semantic HTML

### Pages/Sections
1. **Hero Section**: Eye-catching introduction with call-to-action
2. **Analysis Input**: Clean textarea for ingredient entry with helpful buttons
3. **Results Section**: Hierarchical ingredient breakdown with detailed cards
4. **About Section**: Information about the tool and methodology
5. **Professional Footer**: Clean footer with branding

## 🚀 Getting Started

### Quick Start
1. Simply open `index.html` in any modern web browser
2. No build process or dependencies required!

### Usage
1. **Enter Ingredients**: 
   - Type or paste ingredients from a food product label
   - Separate ingredients with commas
   - Click "Try Sample" to see an example

2. **Analyze**:
   - Click "Analyze Ingredients" button
   - Wait for the analysis (simulated processing time)

3. **Review Results**:
   - See the overall health score
   - Browse ingredients organized by category
   - Click category headers to expand/collapse
   - Use search to filter specific ingredients

## 🎨 Technical Implementation

### Technologies Used
- **HTML5**: Semantic structure with accessibility features
- **CSS3**: Modern styling with custom animations
- **Tailwind CSS**: Utility-first CSS framework (via CDN)
- **Vanilla JavaScript**: No frameworks - pure, efficient JavaScript
- **Google Fonts**: Inter font family for clean typography

### Key Features
- **Responsive Design**: Mobile-first approach with breakpoints for all devices
- **Smooth Animations**: CSS transitions and keyframe animations
- **Dynamic Content**: JavaScript-based content generation
- **Search Functionality**: Real-time filtering without page reload
- **Collapsible UI**: Interactive expand/collapse functionality
- **Progress Indicators**: Animated SVG circular progress bars
- **Color-Coded System**: Visual safety indicators

### Code Structure
- Single HTML file containing:
  - Semantic HTML structure
  - Embedded CSS styles
  - Comprehensive JavaScript logic
  - Complete ingredient database

## 🧪 Supported Ingredient Categories

The application intelligently categorizes ingredients into:

1. **Natural Ingredients**: Whole foods and minimally processed ingredients
2. **Additives & Preservatives**: Chemical compounds that extend shelf life
3. **Artificial Colors & Flavors**: Synthetic compounds for appearance and taste
4. **Sweeteners**: Natural and artificial sweetening agents
5. **Emulsifiers**: Substances that help mix incompatible ingredients
6. **Flavor Enhancers**: Compounds that enhance taste perception
7. **Vitamins & Minerals**: Fortification nutrients
